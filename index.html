⚙️ Settings

手动录入阶段从简（PRD §6.6）。

📄 简历管理（匹配分析用）

支持多份简历；设一份为默认，新建 Job 自动用它匹配。每份可粘贴文本解析或上传 .txt（PDF 视觉解析为预留接口）。

🤖 AI 面试官（可选 · 联网）

模型名规则：火山引擎方舟需填你创建的推理接入点 ID（如 ep-abc123）；其他厂商通常直接填模型名。密钥仅保存在本机浏览器（localStorage），不会上传到任何服务器；调用失败时自动回退脚本逻辑。CORS 代理仅用于「新建 Job」粘贴链接时绕过浏览器跨域限制转发抓取，链接中的 {url} 会被替换为编码后的目标地址；适用于服务端渲染的站点，对 BOSS直聘等 JS 渲染页面无效（此类请用 AI 直接解析链接或粘贴 JD 文本）。
⚠️ 当前浏览器（很可能是以 file:// 方式打开本地文件）禁用了 localStorage，配置无法自动跨会话保存。请点「导出配置」保存为 JSON 文件，下次打开后再「导入配置」即可恢复。

🖼️ 截图视觉模型（可选）

用于「新建 Job」截图解析，复用上方「AI 面试官」的 Base URL 与 Key，此处只需单独填写视觉模型名；留空则截图解析复用默认「模型」。这样 Mock 面试（文本）与截图识别（视觉）可使用不同模型、互不干扰。

🏷️ 能力标签词库（弱项标签 · 固定 + 可扩展）

词库见 PRD §5，按 L1–L5 分层；面试反馈打标累计形成能力图谱。

📤 数据导出

导出全部 Job Application 为结构化文件，便于备份或跨工具分析。
